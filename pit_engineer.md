## About Pit Engineer

**Pit-Engineer** is a small Windows application designed to help people tune their cars in various racing games. In my free time, I enjoy playing racing games and trying to achieve the best lap times. Tuning the car to the track can make a significant difference; however, I had little understanding of how to tune a car to my liking. So, I decided to create a stand-alone version of this tool that can be used next to any racing game on Windows! Later, I also developed an Android version of the app.

## About the Project (Windows)

A racing game called **Project Cars 2** introduced a feature called "Race Engineer," a tool that simplifies tuning and provides suggestions for improvement. However, this tool was only available within Project Cars 2, so I created a stand-alone version using the **.NET framework** and **WPF**, with the questionnaire built using **XML**. This app took about a week of part-time development, with most of the time spent on creating the questionnaire.

## About the Project (Android)

A few months after developing the desktop app, I found it helpful multiple times. However, I noticed that some users, like myself, found it difficult to reach the mouse and keyboard while sim-racing. Therefore, I decided to create a mobile version that is always within reach. I chose Android because it is much more accessible in terms of licensing, plus I do not own an iPhone. Most of the development time went into learning how to extract **XML** data within **Java** and understanding how **Fragment layouts** work.

## My Contribution

This app was entirely created by me, and I accomplished the following:

- Learned and created an XML Schema using [XSD](https://searchmicroservices.techtarget.com/definition/XSD-XML-Schema-Definition)
- Created the entire questionnaire in XML
- Learned and developed the interface using [WPF](https://docs.microsoft.com/en-us/visualstudio/designers/introduction-to-wpf)
- Learned and built the interface using [Fragments](https://developer.android.com/guide/components/fragments)
